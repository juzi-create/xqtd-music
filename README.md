# 崩铁音乐站

个人练习项目：崩坏：星穹铁道（Honkai: Star Rail）的音乐整理与在线试听网站。

## 文件结构

| 文件       |                作用                                  |
| index.html | 页面结构：标题、搜索框、分类卡片、歌曲表格              |
| style.css  | 全部样式：星空背景、卡片、表格、播放器                  |
| songs.js   | 曲库数据：分类和歌曲列表（想加歌就改这里）              |
| app.js     | 功能逻辑：渲染歌单、搜索、播放控制                     |
| server.js  | 开发辅助工具：批量查歌、拉取专辑歌单（网页本身不依赖它） |

## 怎么运行

直接用浏览器打开 `index.html`（双击即可）。

站内播放和搜索通过 JSONP 直连 QQ音乐接口，**不需要启动任何本地服务**。

## 说明

- 接口是 QQ音乐的网页接口，个人学习用途，接口随时可能失效
